# BusDirect

BusDirect est une application web qui permet de consulter les trajets de bus et de gérer les réservations facilement.

## Fonctionnalités

- Afficher, rechercher et filtrer les trajets.
- Naviguer entre les pages avec la pagination.
- Réserver, modifier ou annuler une réservation.
- Afficher les sièges disponibles et occupés.
- Gérer les sièges VIP avec un supplément de 10 %.
- Vérifier les informations des passagers et les numéros de téléphone marocains.
- Gérer la liste d’attente.
- Sauvegarder les données avec LocalStorage.

## Technologies utilisées

- HTML5
- CSS3 / Tailwind CSS
- JavaScript
- JSON
- LocalStorage

## Installation

1. Ouvrir le projet dans Visual Studio Code.
2. Lancer `index.html` avec Live Server.
3. Ouvrir l’application dans le navigateur.
